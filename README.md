# Zb_Agent

面向“可自进化数字员工”的本地优先架构设计，目标是：

- 不在普通笔记本本地跑大模型推理，只做本地索引与编排，响应快
- 具备长效个人习惯记忆 + 项目全周期记忆
- 支持本地超大行业知识库与本地源码索引
- 全程国内生态、国内正规大模型 API、最小化数据外发

---

## 1. 总体架构（本地智能体框架 + 本地 RAG + 国内大模型 API）

```text
┌───────────────────────────────────────────────────────────────────┐
│                           本地控制平面（Laptop）                   │
│                                                                   │
│  ┌───────────────┐   ┌────────────────┐   ┌────────────────────┐  │
│  │ 任务编排引擎   │──▶│ 工具/流程执行层 │──▶│ 归档与沉淀（记忆回写） │  │
│  └───────┬───────┘   └────────────────┘   └────────────────────┘  │
│          │                                                        │
│          ├──────────────▶ 长效记忆库（习惯/风格/规范/偏好）         │
│          ├──────────────▶ 项目记忆库（里程碑/决策/故障/变更）       │
│          ├──────────────▶ 本地知识库（文档解析+向量索引）           │

           ▼
   国内正规大模型 API（推理与生成）
```

## 2. 本地做的事（全部不出笔记本）

### 2.1 长效记忆库
- 记录个人工作习惯、行文风格、编码规范、架构偏好
- 记录“用户级偏好（跨项目）”与“项目级约定（当前仓库）”的边界
- 在任务完成后自动回写记忆（去重、版本化、可追溯）

### 2.2 本地知识库（RAG）
- 批量导入消防/楼宇/ARM/工控规范、方案、源码、手册
- 本地文档清洗、分块、向量化与索引构建
- 检索优先本地知识，外部信息仅作补充且需标注来源

### 2.3 任务编排
- 自动拆解任务：目标 → 子任务 → 执行计划 → 验收清单
- 自动整理资料、归档过程产物与结论
- 形成可复用 SOP，逐步提升后续任务效率与稳定性

### 2.4 源码本地索引
- 本地构建工程结构图、调用链、模块依赖关系
- 问答和改码时优先引用本地索引结果，避免上传完整源码
- 对敏感目录支持排除索引与权限分层

---

## 3. 关键约束与目标

1. **普通笔记本不做本地大模型推理**：本地只做索引、检索、编排
2. **全程国内生态**：仅使用国内正规大模型 API 与可控服务
3. **安全与合规优先**：
   - 默认最小外发（只传必要片段，不传完整资料/源码）
   - 全链路审计（谁在何时发送了什么上下文）
   - 数据分级（公开/内部/敏感）与策略路由
4. **低幻觉高严谨**：
   - 回答必须可溯源（引用本地知识片段或代码定位）
   - 无证据不下结论，冲突信息优先触发“需人工确认”
5. **可自我学习进化**：
   - 从任务复盘中提炼可复用策略
   - 失败案例进入“负样本记忆”，降低重复犯错概率

---

## 4. 能力闭环（项目全周期）

`项目方案 → 自动拆解 → 资料检索与汇总 → 编码实现 → 测试验证 → 运维维护 → 复盘沉淀`

通过本地记忆与本地索引持续积累上下文，形成“越用越懂你、越做越稳”的数字员工。
